# Archive

Historical scripts from WikiGraph development. These are one-off utilities used
during data import, validation, debugging, migration, and analysis phases.

**Not part of the active codebase.** No active code imports from this directory.
Preserved for reference and reproducibility of historical operations.

## Categories

- **validate_*** / **verify_*** -- Data validation and integrity checks
- **debug_*** / **diagnose_*** / **inspect_*** -- Debugging and diagnostics
- **migrate_*** / **update_*** / **add_*** -- One-time schema/data migrations
- **analyze_*** / **classify_*** / **audit_*** -- Data analysis and profiling
- **rescue_*** -- Emergency data repair scripts
- **cleanup_*** -- Historical cleanup operations
